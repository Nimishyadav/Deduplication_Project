## Overview

This project focuses on detecting duplicate text/question pairs using multiple Natural Language Processing (NLP) and Machine Learning techniques.

The system compares three approaches:

1. TF-IDF + Cosine Similarity (Baseline)
2. MinHash with Locality Sensitive Hashing (LSH)
3. Logistic Regression using handcrafted similarity features

The project evaluates model performance using:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

It also generates visualization plots and CSV reports for comparative analysis.
